## 二、登录codex
1. 一般来说，打开了codex之后，就会显示继续登录和另一种方式登录（就是api登录），api的网站有很多，大家可以自己去搜索，<font style="color:#DF2A3F;">接下来介绍我们自己的账号登录codex</font>，所以就需要我们有一个自己的chatgpt账号，推荐使用google浏览器，下载地址：[Google浏览器](https://www.google.com/chrome/)
2. google浏览器搜索chatgpt，第一个即可

后续登录注册，直接使用google账号即可，后续完成注册之后就可以登录chatgpt了，登录之后如图

到达这一步了之后，就可以登陆我们的codex软件了。

### 三、登录应用codex
1. 打开codex应用，选择继续登录即可，一般来说新注册的都跳不过这个手机号码验证环节，接下来推荐一个老牌的接码平台，就是5sim，网址如下：[5sim网址](https://5sim.com/)
2. 接下来告诉大家操作，以及充值办法，最便宜的我们只需要1美元即可，注意5sim平台注册登录环节需要自己完成，进来页面如下：

<img src="https://cdn.nlark.com/yuque/0/2026/png/49968491/1786962518395-ce25339f-3f0d-4ce5-b490-4b9dfdb487da.png" width="1698" title="" crop="0,0,1,1" id="u4002dde3" class="ne-image">

3. 点击钱包就可以充值了，点击第四个就可以使用云闪付（union pay，也就是银联支付）或者支付宝支付，但是支付宝最低需要充值5美元，选择第二张图片里面的UnionPay即可，然后就是付款了，自己有银行卡的话，可以在云闪付上面绑定卡，<font style="color:#DF2A3F;">然后若是不可以付款的话，需要在银行卡上面开通境外支付选项（在你自己对应的银行卡的app上面开通即可，我的建设银行卡可以设置有效期，设置一天即可）</font>

<img src="https://cdn.nlark.com/yuque/0/2026/png/49968491/1786962560051-4c95af4e-cfff-43c0-936f-5178bde7e970.png" width="1705.3333333333333" title="" crop="0,0,1,1" id="u8257de38" class="ne-image">

4. 支付完成之后，余额便会显示出来了，在左侧Select service搜索chatgpt，选择OpenAI即可，

<img src="https://cdn.nlark.com/yuque/0/2026/png/49968491/1786962875064-dbe6ac7d-5f7f-4f63-bed3-1410ec5cecc6.png" width="1559.3333333333333" title="" crop="0,0,1,1" id="u9d20dbf6" class="ne-image">
